# Intro to R - Session 1

Research seminar for ABC. November 2026. 

## Objectives

- Give an overview of the state of replicability and reproducibility in science
- Explore how coding in general, and R in particular might help with this situation
- Demo a small workflow for combining data, code, and output in a template Elsevier journal manuscript



### Local Setup

Requirements:

- R
- RStudio

## Important dependencies

Quarto is needed for rendering the presentation and the two journal manuscripts.

### Key packages

- quarto-journals
  - elsevier
  - plos

## Usage examples

Generate presentation:

```bash
quarto render Intro_to_R_Session_1.qmd
```
